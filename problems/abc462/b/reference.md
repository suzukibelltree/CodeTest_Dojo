# abc462 b 解説の材料

## 問題概要
N人（1〜N）がギフトを交換した。人iはK_i人（A_{i,1} < ... < A_{i,K_i}）にギフトを送った。
各人iについて、「その人にギフトを送った全員」を昇順で求めて出力する。

- 制約: 2≤N≤100, 1≤K_i≤N-1, A_{i,j}≠i
- 入力: i行目に K_i と送信先リストが与えられる
- 出力: i行目に「受け取った人数 X」と「送り主の番号（昇順）」を出力

### サンプル1
入力
```
4
1 2
1 3
1 2
3 1 2 3
```
出力
```
1 4
3 1 3 4
2 2 4
0
```
（人1は人4から、人2は人1,3,4から、人3は人2,4から受け取り、人4は誰からも受け取っていない）

## 公式解説
URL: https://atcoder.jp/contests/abc462/editorial/21457

要点: 「誰が誰にギフトを送ったか」を入力そのまま使うのではなく、逆方向（誰が誰から受け取ったか）を
二次元配列（vector<vector<int>> など）に貯め直してから出力すればよい。

- `recv[j]` を「人jが受け取った送り主のリスト」とする配列を用意
- 人iの送信先リスト A_{i,1..K_i} を読みながら、各 c について `recv[c-1].push_back(i+1)` のように追加
- 人iを1→Nの順に処理し、各iの中では送信先が昇順で与えられているため、`recv[j]` に追加される順序も
  自動的に送り主番号の昇順になる（ソート不要）
- 最後に各jについて「サイズ」+「中身」を出力するだけ

計算量は O(ΣK_i) で N≤100 なので十分高速。

## 解き直し後のACコード
```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    cin.tie(nullptr);
    ios::sync_with_stdio(false);

    int n;
    cin >> n;
    vector<vector<int>> recv(n);
    for (int i = 0; i < n; i++)
    {
        int k;
        cin >> k;
        for (int j = 0; j < k; j++)
        {
            int a;
            cin >> a;
            recv[a - 1].push_back(i + 1);
        }
    }

    for (int i = 0; i < n; i++)
    {
        cout << recv[i].size();
        for (int x : recv[i]) cout << ' ' << x;
        cout << '\n';
    }

    return 0;
}
```

## 詰まったポイント
- 「送った人→送信先」の入力を、そのまま出力形式（「受け取った人→送り主」）に変換する発想に気づけなかった。
- ポイントは向きを逆転させるだけで、i=1→Nの順に処理すれば送り主番号は自動的に昇順になる（ソート不要）。
