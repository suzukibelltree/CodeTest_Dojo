# abc381 c 解説の材料

## 問題概要 (11/22 String)
文字列 T が「11/22文字列」であるとは、以下をすべて満たすこと。

1. 長さが**奇数**
2. 最初から中央の1文字前まではすべて `1`
3. 中央の1文字は `/`
4. 中央の次から最後まではすべて `2`

（例: `11/22`, `111/222`, `/` は該当。`1122`, `1/22` は非該当）

与えられた文字列 S（`1`,`2`,`/` からなる、長さ N、`/` を1個以上含む）の**部分文字列**のうち、11/22文字列になっているものの最大長を求める。

## 制約
- 1 ≤ N ≤ 2×10^5

## 現状のコードがTLEする理由
`main.cpp` は「開始位置 i」「長さ j」を全通り試して `substr` を作り `check()` にかける、という O(N^2) 通りの部分文字列 × O(N) の切り出し/判定 = **O(N^3)** の全探索。N=2×10^5 では到底間に合わずTLEになる（log.csvのnote「計算量の削減方法がわからない」に対応）。

## 公式解説
URL: https://atcoder.jp/contests/abc381/editorial/11413

### 想定解法（O(N)）
11/22文字列は必ず1個の `/` を中心に「左に1がd個、右に2がd個」という対称な形をしている（長さ = 2d+1）。なので**部分文字列を全部試す必要はなく、各 `/` を中心に左右にどこまで伸ばせるかだけ**を考えればよい。

- `/` の位置を i とする
- その直前まで連続する `1` の個数を `leftOnes`
- その直後から連続する `2` の個数を `rightTwos`
- d = min(leftOnes, rightTwos) が、その `/` を中心にできる最大の11/22文字列の半径
- 候補の長さ = `2*d + 1`

これを全ての `/` について求め、最大値を答えとする。

`leftOnes` と `rightTwos` は事前に**累積の連続個数配列**を1回のループで前計算しておけば、各 `/` に対する計算はO(1)になり、全体で **O(N)**。

- `cnt1[i]` = 位置 i の直前まで（0-indexedで s[0..i-1]）に何個連続で `1` が続いているか
  - `cnt1[i+1] = s[i]=='1' ? cnt1[i]+1 : 0`
- `cnt2[i]` = 位置 i から後ろ（s[i..]）に何個連続で `2` が続いているか
  - `cnt2[i] = s[i]=='2' ? cnt2[i+1]+1 : 0`（後ろから前へ計算）

各 `/`（位置i）について `leftOnes = cnt1[i]`, `rightTwos = cnt2[i+1]` として `2*min(leftOnes,rightTwos)+1` を候補にする。

## 解き直し後のACコード
サンプル1（`/1211/2///2111/2222/11` → 期待値 `7`）で検証済み。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    cin.tie(nullptr);
    ios::sync_with_stdio(false);

    int n;
    string s;
    cin >> n >> s;

    // cnt1[i] : s[0..i-1] の末尾から続く '1' の連続個数
    vector<int> cnt1(n + 1, 0);
    for (int i = 0; i < n; i++)
        cnt1[i + 1] = (s[i] == '1') ? cnt1[i] + 1 : 0;

    // cnt2[i] : s[i..n-1] の先頭から続く '2' の連続個数
    vector<int> cnt2(n + 1, 0);
    for (int i = n - 1; i >= 0; i--)
        cnt2[i] = (s[i] == '2') ? cnt2[i + 1] + 1 : 0;

    int ans = 1; // "/" 単体（長さ1）は必ず条件を満たす
    for (int i = 0; i < n; i++)
    {
        if (s[i] == '/')
        {
            int leftOnes = cnt1[i];
            int rightTwos = cnt2[i + 1];
            int d = min(leftOnes, rightTwos);
            ans = max(ans, 2 * d + 1);
        }
    }

    cout << ans << endl;
    return 0;
}
```

## 詰まったポイント
- 部分文字列を全列挙して都度チェックするとO(N^3)で確実にTLEする（N=2×10^5）
- 「11/22文字列は `/` を中心とした対称構造」という性質に気づけるかがカギ。全探索ではなく「各 `/` について左右にどこまで同じ文字が続くか」だけを見ればよい
- 連続する `1`・`2` の個数は前計算（前方/後方への累積カウント）で O(N) に落とせる
