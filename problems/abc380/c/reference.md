### 問題概要
`0`と`1`のみからなる長さ`N`の文字列`S`が与えられる。「1の塊」（連続する1で、前後が0または文字列端で区切られる部分）は`S`の中に複数あり、そのうち**K番目の1の塊を、K-1番目の1の塊の直後に移動**させた結果の文字列を出力する。

制約:
- `1 ≤ N ≤ 5×10^5`
- `K ≥ 2`
- `S`には少なくともK個の1の塊が存在する

### 操作の言い換え（ここが方針のキモ）
「K番目の1の塊をK-1番目の直後に移す」というのは、見方を変えると **「K-1番目の1の塊とK番目の1の塊の間にある0の塊」と「K番目の1の塊」を、そのまま入れ替える** という操作に等しい。

```
... [K-1番目の1塊] [0の塊(長さG)] [K番目の1塊(長さL)] ...
      ↓ 入れ替え
... [K-1番目の1塊] [K番目の1塊(長さL)] [0の塊(長さG)] ...
```

それ以外の部分（K番目の塊より前・後ろ）は一切変化しない。K≥2が保証されているので、K番目の1塊の直前には必ずK-1番目の1塊との間の0塊が存在し、境界処理に困らない。

### 解法（O(N)）
1. 文字列を1回走査し、以下を記録する
   - `tail_idx` : K-1番目の1塊の**末尾**インデックス
   - `head_idx` : K番目の1塊の**先頭**インデックス
   - `L` : K番目の1塊の長さ
2. 0塊の長さは `G = head_idx - tail_idx - 1` で求まる（=K-1番目の塊とK番目の塊の間にある0の個数）
3. 新しい文字列は次のように再構成できる
   - `S[0 .. tail_idx]`（そのまま）
   - `'1'` × `L`（移動してきたK番目の塊）
   - `'0'` × `G`（元K-1,K塊間にあった0塊）
   - `S[head_idx+L .. N-1]`（K番目の塊より後ろはそのままコピー）

これで文字列全体を`O(N)`で構築できる。

### 詰まりポイント（自分の実装との比較）
`main.cpp`の実装は「塊の交換」という発想自体は正しい方向だったが、2箇所ズレがあった。

- **0塊の長さの取り違え**：`Kbrock_length`（K番目の1塊の長さ`L`）を、移動後に置く0の個数としても使っていた（`for (int i = idx + 1; i <= idx + Kbrock_length; i++) s[i] = '0';`）。しかし置くべき0の個数は`L`ではなく`G = head_idx - tail_idx - 1`（K-1塊とK塊の間にあった0の個数）。この2つの長さが一致しない場合（サンプル1がまさにそう。`L=2`だが`G=3`）、書き換える範囲がズレて後ろの文字（次の1塊など）を壊してしまう。
- **末尾側の再構成が抜けている**：0塊を書いた後、`head_idx + L`より後ろの部分（K番目の塊より後ろにある他の1塊や0）はそのままコピーされるべきだが、実装では範囲だけ埋めて残りを検証していない。ズレた`G`のせいで、後続のブロックの位置がそのまま正しい保証がなくなる。

サンプル1 (`010011100011001`, N=15, K=3) で確認すると:
- 1の塊: `[1]`(idx1,len1), `[4-6]`(len3), `[10-11]`(len2), `[14]`(len1)
- K=3番目の塊 → `head_idx=10, L=2`。K-1=2番目の塊の末尾 → `tail_idx=6`
- `G = 10 - 6 - 1 = 3`（`L=2`とは異なる！ここを`Kbrock_length`のまま流用すると壊れる）
- 正しい再構成: `S[0..6]="0100111"` + `'1'×2="11"` + `'0'×3="000"` + `S[12..14]="001"`
  → `"0100111" + "11" + "000" + "001"` = `010011111000001` ✅ 期待値と一致

### 実装方針まとめ
- 1回の走査で `tail_idx`, `head_idx`, `L` を求める（実装済みの走査ロジックはほぼそのまま使える）
- 0で埋める個数は必ず `head_idx - tail_idx - 1` を使う（`L`を流用しない）
- `head_idx + L`以降は元の`S`をそのままコピーする（0埋め・1埋めで再構成しようとしない。後ろにどんな塊が続くか分からないため）

## 解き直し後のACコード
<!-- 解けなかった場合、後で解き直してACしたコードをここに貼る (無ければ空でOK) -->

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    cin.tie(nullptr);
    ios::sync_with_stdio(false);

    // ここに解法を書く
    int n, k;
    cin >> n >> k;
    string s;
    cin >> s;
    int brockNum = 0;
    int tail_idx = 0;
    int head_idx = 0;
    int L = 0; // K番目の1塊の長さ
    int G = 0; // K-1番目の1塊とK番目の1塊の間にある0の個数
    // S全体を走査してk-1番目の塊の末尾とk番目の塊の先頭を特定する(計算量：0(N))
    for (int i = 0; i < n; i++)
    {
        if (s[i] == '0')
        {
            continue;
        }
        // 1の塊が始まる時の処理
        bool isBrockStart = (s[i] == '1' && (i == 0 || s[i - 1] == '0'));
        if (isBrockStart)
        {
            brockNum++;
            if (brockNum == k)
            {
                head_idx = i;
            }
        }
        // 1の塊が終わる時の処理
        bool isBrockEnd = (s[i] == '1' && (i == n - 1 || s[i + 1] == '0'));
        if (isBrockEnd)
        {
            if (brockNum == k - 1)
            {
                tail_idx = i;
            }
            if (brockNum == k)
            {
                L = i - head_idx + 1;
                break;
            }
        }
    }
    G = head_idx - tail_idx - 1;
    // cout << "brockNum: " << brockNum << " tail_idx: " << tail_idx << " head_idx: " << head_idx << " L: " << L << " G: " << G << endl;
    for (int i = 0; i <= tail_idx; i++)
    {
        cout << s[i];
    }
    for (int i = 0; i < L; i++)
    {
        cout << '1';
    }
    for (int i = 0; i < G; i++)
    {
        cout << '0';
    }
    for (int i = head_idx + L; i < n; i++)
    {
        cout << s[i];
    }
    cout << '\n';
    return 0;
}
```
